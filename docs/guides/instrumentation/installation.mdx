`instro` is published on [PyPI](https://pypi.org/project/instro/), and can be installed using either [`uv`](https://docs.astral.sh/uv/) (recommended) or `pip`. `instro` supports Python 3.10-3.14.
```bash
$ uv add instro # or 
$ pip install instro 
```

## Additional Packages

`instro` has additional packages for utilizing vendor instruments that require their own dependencies.  These are grouped by indivdual vendors and by instrument type where useful. 

```bash
# replace 'uv add' with 'pip install' if your a pip'er 
$ uv add "instro[nidaq]"   
$ uv add "instro[daq]"  # or install all daq packages
$ uv add "instro[all]"  # install everything
```
<Info>These packages supply Python dependencies. See [Driver Dependencies](/instrumentation/driver-dependencies) for  external installers  required for some instruments.</Info>
Here is a table of available packages:

| Class | Package | Contents |
| --- | --- | --- |
| **All** | `all` | All drivers in this table|
| **DAQ** | `daq` | All DAQ drivers |
|  | `nidaq` | NI DAQ package |
|  | `mccdaq` | Measurement Computing (MCC) package |
|  | `labjack` | LabJack package |
| **I2C** | `i2c` | All I2C packages |
|  | `aardvark` | TotalPhase Aardvark package |
| **EtherNet** | `ethernetip` | EtherNet/IP support |
| **Other** | `contrib` | Community-contributed drivers |
|  | `unstable` | Experimental unstable modules |

 
 


## Using Nominal Connect

If you're a Nominal Connect user, you don't need to install `instro` yourself. Just add it to your packages list in your `app.connect` file, and Nominal Connect will install it into your Python environment automatically. Use any of the [additional packages](#additional-packages) above to pull in more support.

```yaml
python:
  packages:
    - instro[daq]
```
